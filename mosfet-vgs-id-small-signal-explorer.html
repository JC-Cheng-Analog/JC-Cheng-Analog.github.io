How this explorer works / 這個工具在看什麼

The gate signal changes drain current through transconductance. The drain current then creates a voltage drop across RD,high, so the drain voltage moves in the opposite direction. In small signal, the local voltage gain is approximately Av = −gm,loadedRD,high.

Gate 的小訊號先透過 gm 造成 ID 變化，再由 RD,high 把電流變化轉成反相的 Drain 電壓。最後一張圖會把 VGS 與 VDS 的 AC component 疊在同一個電壓刻度， 可以直接比較增益與反相關係。

Small-Signal Meaning

β = M · μCox · (W/L)
id ≈ gmvgs + gdsvds
vds = −idRD,high  (AC, VDD is AC ground)
⇒ id ≈ [gm / (1 + gdsRD,high)] · vgs
Av,Q = dVDS/dVGS ≈ −gm,loadedRD,high
VGS(θ) = VGS,Q + A·sin(θ), 0 ≤ θ ≤ 4π
THD = √(I₂² + … + I₁₀²) / I₁

這版的核心不是讓 VDS 去「推動」ID，而是讓 vgs 透過 gm 產生 id。 RD,high 再把電流變化轉成 drain voltage 變化。當 swing 太大時， square-law 的 gm 本身會隨 VGS 改變；若 VDS 又被拉低到 VOV 以下，還會進一步跨入 triode， 因此輸出電流不再是理想正弦。
