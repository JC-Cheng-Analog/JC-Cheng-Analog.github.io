PURPOSE
-------
This file is the master outline for the Study Map.
Use indentation to represent hierarchy.

FORMAT
------
[GROUP] = expandable category; no separate HTML page required.
[PAGE][AVAILABLE] = clickable page that already exists.
[PAGE][PLANNED] = clickable page planned for generation.

Each page line follows:
[PAGE][STATUS] Display Title | filename.html

MANAGEMENT RULES
----------------
1. Add, remove, rename, or move an item in this file first.
2. Keep every HTML filename lowercase and use hyphens between words.
3. Do not reuse one filename for unrelated topics.
4. When a planned page is created, change [PLANNED] to [AVAILABLE].
5. For a large map, use this file as the single source of truth and run a generator script to:
   - update the Study Map section in index.html;
   - create missing HTML pages from the page template;
   - preserve existing completed pages;
   - report duplicate filenames or broken links.
6. The generator script will be prepared during Step 3 after the first page is reviewed.
